# 论文式中西文字体与检查

用于正式中文综合实践报告的字体设置、修订与验收。先采用用户或学校明确提供的论文细则；仅提供参考样例的结构、内容与风格要求时，分别检查字体，不能将样例的办公主题字体当作论文要求。

## 默认字体分工

没有机构字体细则或用户指定时，使用以下报告排版约定。各校要求可能不同，此约定不作为统一的高校论文标准。

| 对象 | 中文及中文标点 | 英文、阿拉伯数字及普通技术标识 |
|---|---|---|
| 正文、摘要、目录条目 | 宋体（SimSun） | Times New Roman |
| 封面标题、章节标题、目录标题 | 黑体（SimHei） | Times New Roman；加粗与标题样式一致 |
| 表格、图表题注、参考文献 | 宋体（SimSun）；表头按模板加粗 | Times New Roman |
| 页眉、页脚、页码 | 宋体（SimSun） | Times New Roman |
| 原生数据图表的标签、坐标、图例 | 宋体（SimSun）；标题可按已确认图表样式使用黑体 | Times New Roman |
| imagegen 示意图的短标签 | 提示词要求宋体字形；标题可按已确认风格采用黑体 | 提示词要求 Times New Roman 字形 |

字号、行距、颜色、版心和编号按用户、机构或已确认模板单独设置。仅修改字族时保留这些已确认属性，字体引起的分页变化则重新检查。公式及整段代码需要专用字体时，按机构的专门规定设置并记录例外；普通行内型号、单位、标识符和参考文献仍采用上述西文字体。

原始照片、实测截图和软件界面截图中的文字保持原貌。新增的图外题注采用报告字体。实测数据图表采用原生可编辑图表并核对实际字体；流程、架构、状态等新生成或重制示意图片统一采用 imagegen，详见 [生成图规则](visual-docx-qa.md#生成图与重制图)。提示词指定上述中西文字形，逐图检查字形、缺字及可读性；不能依据提示词或位图宣称其内部字体文件已被验证。需要精确长说明时将其放在可编辑正文或图外，不用代码叠字或修改真实截图来实现字体统一。

## DOCX 设置要点

`font.name` 通常只设置西文字体，不能单独证明中文字体正确。至少分别设置：

```xml
<w:rFonts w:eastAsia="SimSun"
          w:ascii="Times New Roman"
          w:hAnsi="Times New Roman"
          w:cs="Times New Roman"/>
```

中文标题将 `w:eastAsia` 改为 `SimHei`。覆盖实际使用的正文、标题、封面、目录、表格、题注、参考文献、页眉页脚和域结果。检查文档默认值、段落样式、字符样式、`basedOn` 继承及直接格式；不能只改 Normal 样式而留下其他位置的 Calibri 或等线。

明确字体和主题字体同时存在时，`asciiTheme`、`hAnsiTheme`、`eastAsiaTheme`、`cstheme` 等属性可能使实际字形与显式字体名不同。移除与本轮规范冲突的主题属性，或同步修正主题的 major/minor、Latin、East Asian 及 Hans/Hant 字体并验证有效值。不得只写显式字体名、保留冲突主题，再凭名义设置判断通过。

标题字体优先写在标题样式中。标题 run 的直接字体可能被 Word 复制进自动目录，使目录条目跟随标题变成黑体。清理标题中的重复或冲突直接字体，让标题通过样式取得字体；完整更新目录后再检查目录条目，不能只在更新前手工修改目录结果。保留目录域及超链接，不将目录改成静态文本。

先确认渲染环境确实拥有所需字族。缺失字体或出现回退时，记录实际替代及受影响位置；用户明确规定的字族尚未实现时，不声称字体合规。

## 检查与交付

1. 对有效字体做检查，解析直接格式、字符样式、段落样式、文档默认值和主题；同时验证 East Asian 与 ASCII/hAnsi 槽。字体表中未使用的字体名称不等于实际使用的字体。
2. 比较上一版，确认技术参数、正文、表格、参考文献、图片位置和数量只出现本轮允许的变化；字体修订形成新版本，保留原稿。
3. 用实际 Word、LibreOffice 或等效排版器完整更新目录与页码、保存并渲染。核对渲染 PDF 的文字字体名称或使用等效字体检查能力，识别替换字体；西文加粗、斜体应是规定字族的对应变体。
4. 逐页查看渲染图片，检查中英混排、标题、目录、表格、题注、参考文献、页眉页脚和所有新生成图表，修正缺字、字形不一致、换行溢出、图题跨页和页码变化。
5. 保存最终文件哈希、渲染页数、有效字体与实际字体检查结果，以及最终页面检查记录。无法完成实际字体或渲染检查时，说明检查范围；XML 字体名正确不等于实际版面检查通过。
