# 工程与论文配图画法

用于流程、状态、时序、软件结构、接口、电路和机械装配等工程图片。先确定说明对象和图的类型，再选用该类型的符号、线型和关系语义，最后通过 `$imagegen` 生成 PNG/JPEG。图像生成方式与工程记法是两项独立要求，外观整齐不能代替符号和逻辑正确。

## 规范依据

- 流程图：参照 [ISO 5807:1985 — 信息处理文档符号及流程图约定](https://www.iso.org/standard/11955.html)。核对符号类别和连接约定，按公开可获取的标准内容及项目实际使用；不声称取得未获取的付费全文。
- UML 状态、活动、包、组件与时序记法：参照 [OMG UML 2.5.1 官方入口](https://www.omg.org/spec/UML/2.5.1/)及其[规范全文](https://www.omg.org/spec/UML/2.5.1/PDF)。按所用图类型查阅相应 Notation 小节，不混用不同类型的符号。
- 元器件电路原理图：参照 [IEC 60617 电气图形符号数据库](https://webstore.iec.ch/en/publication/2723)，器件引脚与电气参数另外核对实际型号的官方手册；系统接线框图不冒称完整电路原理图。
- 机械轴测图及爆炸示意图的投影：参照 [ISO 5456-3:1996](https://www.iso.org/standard/11503.html)。该规范提供轴测投影依据，部件结构、编号及展开顺序仍须真实 CAD、实物照片和器件清单支持。
- 参考相关论文时读取实际图例，记录题名、DOI 或稳定链接、页码与图号；只采用与本项目对象及所选图类型一致的表达，不直接复制其他项目的技术关系。
- 学校或期刊明确指定其他规范时优先采用，并记录名称、版本和可核验来源。仅要求论文风格时选择适合工程对象的通行画法，不虚构某一统一的论文配图标准。

官方规范入口核对日期：2026-10-11。只查目录、摘要或局部记法时，不声称通过整项标准的完整合规认证。所选规范及论文不改变 imagegen 成图和禁止 SVG、代码绘图及转码替代的要求。

## 按图类型执行

- 流程图采用明确的起止符号、处理矩形、输入输出平行四边形和判断菱形。箭头表示执行顺序，判断出口标明条件或“是／否”，分支与回路必须能够完整追踪。不能将所有步骤都画成装饰性圆角卡片。
- UML 状态图采用状态圆角矩形、初始实心圆及有向迁移线；只有实际存在终止状态时使用终止标记。迁移写明事件、条件及必要动作，采用 `事件 [条件] / 动作` 表示。循环待机系统不补造结束状态。
- UML 活动图区分初始、活动、决策／合并、分叉／汇合和终止；分叉表示并发，不能用于普通顺序步骤。泳道表示责任主体，不表示执行先后。
- UML 时序图明确参与者、生命线和时间先后，按真实调用或通信方式区分同步、异步与返回消息；必要时使用条件、循环等组合片段。箭头方向、消息名称和参数与代码或协议一致，不用任意水平箭头代替完整的交互语义。
- UML 包图采用带页签的包形状；依赖为虚线开放箭头，从使用方指向被依赖方。组件图采用规范组件记法及真实接口；不补造类、继承、接口或调用关系。
- 软件体系结构框图采用清晰的模块矩形、系统边界与接口连接，注明数据或控制含义和方向。框图不自动称为 UML 组件图；箭头不能同时含混地表示隶属、调用、供电和时序。
- 数据格式与编码关系图区分数据对象、处理步骤及外部服务，在线旁标明数据类型或编码，分流与汇合有确定含义；不同封装格式、传输编码及其转换关系须与源码或协议一致，不将独立数据支路误连。
- 硬件接口图采用模块边界、明确的端口和逐线连接。电源、地、数据与控制信号分清，注明 TX/RX 方向、有效电平和接口参数。仅表达引脚对应的框图不冒称完整电气原理图。
- 元器件电路图区分导线相交和电气连接，核对连接点、极性、电源、地、器件位号、引脚及网络名称。元器件值或内部连接没有资料支持时不补造电路；只能确认模块间关系时绘制系统连接框图。
- 协议帧图采用从左至右的字节字段格、字段宽度、次序与长度标注。变量区与固定字段区别清楚，端序及长度公式与源码一致；图示时间或宽度不伪装成实测数据。
- 结构叠装图与成果组成图采用剖面、层级或关系表示。尺寸、零件、层次与连接均有资料支持；组成关系不画成虚假的运行顺序。
- 机械爆炸图采用一致的工程投影，沿真实装配轴展开，编号对应部件清单，零件数量、外形、尺度关系和朝向保持一致；没有测量或 CAD 依据时不新增尺寸、公差和紧固规格。生成示意图不作为制造图或实物照片。

## imagegen 提示词与验收

每张图的提示词明确：图类型、规范版本或参考论文、符号形状、完整节点和标签、全部边的类型与起止方向、分支条件、数据或接口名称、真实参考资料、布局和字形。逻辑可用文字清单或 JSON 描述，不生成 SVG、Mermaid 或其他绘图代码。采用白底、深色细线、低彩度或黑白配色，图内无重复标题、阴影和装饰。中文宋体风格，英文及数字 Times New Roman 风格；精确长说明放在可编辑正文和图外。字体、线宽与配色是报告排版约定，不冒称国际规范的强制条款。

成图逐张核对内容与所选记法：符号是否使用正确、箭头是否落在边界、分支去向是否明确、连线是否穿字或交叉产生歧义、模块与端口是否对应、标签和数字是否准确；机械图另核对投影、零件与装配关系。错误通过 imagegen 定向修订，不用 SVG 或代码重绘、叠字来代替。生成记录注明图号、图类型、规范依据、项目事实来源、实际提示词、成图路径及哈希；符合常用记法的局部图示不能夸大为整项软件符合 UML 标准。不能仅凭 PNG/JPEG 扩展名或 DOCX 结构审计认定生图来源合规。
