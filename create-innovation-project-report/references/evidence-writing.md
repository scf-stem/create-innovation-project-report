# 资料支持程度与写作规则

以下分类只用于内部工作。成稿使用“当前状态、完成范围、测试结果、后续安排”等项目语言，不增加“资料依据”章节或索引。

## 资料与结果分类

### A 类：实现与结果记录充分

包括源码、配置、运行截图、测试记录、输出文件或实物照片，并能相互印证。

可以写：

- 已完成模块实现
- 完成接口联调
- 在指定场景下观察到某项结果

仍不得把单次或局部验证概括为长期稳定运行。

编译日志只能证明工程通过编译，不能证明程序已在硬件上正确运行。界面截图若显示报错、告警、未连接或状态未知，只能作为问题记录或局部界面资料。

### B 类：有实现资料，但结果记录不完整

包括完整源码、模型、图纸或配置，但缺少可核验的系统级测试记录。

建议写：

- 完成该模块的实验性实现
- 搭建实验性方案
- 具备进一步联调基础

不要写准确率、实时性、成功率、稳定性等结论。

### C 类：只有方案或参考资料

只有说明文档、示例工程、论文、教程或计划。

建议写：

- 形成技术路线
- 完成原理分析和方案设计
- 作为后续实现或优化方向

不要写“已实现”“已验证”“已部署”。

## 内部事实清单字段

为每项核心内容记录：

- 报告章节
- 模块或功能
- 资料路径
- 资料类型
- 可支持的事实
- 尚不能支持的结论
- 推荐措辞
- 需要补充的图片或测试

内部事实清单用于写作过程，不作为“资料依据”章节放进成稿。

## 技术内容写法

先写工程对象，再写动作和结果：

- 弱：系统具有较好的智能化水平。
- 强：识别节点接收相机图像，输出类别状态；导航层依据状态决定继续执行或停车等待。

先写接口，再写关系：

- 输入是什么
- 如何处理
- 输出到哪里
- 失败时如何处理

将“设计意图”和“验证结论”分开：

- 设计意图：为降低误识别对运动控制的影响，增加连续帧确认。
- 验证结论：只有存在记录时才说明观察结果；否则写为待后续系统测试。

## 指标审查

遇到以下内容必须回查原始资料：

- 百分比、毫秒、帧率、速度、距离、功耗、误差
- “稳定”“实时”“高精度”“显著提升”
- “达到”“满足”“优于”“成功完成”
- 测试次数、运行时长、数据集规模

无法定位到记录时，删除数字或改为实验性描述。

## 重复资料与测试记录

- 对同名、同尺寸或处于重复目录的源码、模型、图片和文档进行内容比较。
- 内容相同的副本按一项成果统计，不因出现多份而提高资料支持程度。
- 测试表中的“检查方法”“预期结果”属于测试设计；只有实际观察、日志、截图或结论字段才能支持结果判断。
- 示例数据、图库图片和通用演示不能替代真实项目输入或实测结果。

## 编写过程说明清理

以下内容只用于内部工作，不进入项目成稿：

- 资料依据与编写口径
- 文件夹扫描说明
- AI 生成或润色说明
- 自检过程
- 为凑篇幅设置的附录
- 与项目没有直接关系的参考资料列表

若用户或提交机构明确要求参考文献、诚信声明或格式说明，则按其模板保留。

## 成稿独立性与直接叙述

内部保留来源路径、视频时间点、测量原表和判断过程；正文写清这些材料支持的工程事实。读者无需打开会议录像、聊天附件或内部清单才能理解关键结论。必要的图、表、参数、操作步骤和测试条件应纳入成稿；参考链接用于追溯或延伸阅读。

按“对象—做法或关系—条件—结果”改写，不按关键词批量删除：

| 待改善表述 | 改写方式 |
|---|---|
| 某日设计截图展示模块关系 | 图题写“控制与供电连接关系”，正文解释供电路径、控制信号和接口；日期仅在版本或实验条件有意义时保留 |
| 根据口述记录完成安装 | 写清实际装配顺序、定位方式和连接对象；支持程度不够时只写已确认步骤，不补造安装细节 |
| 该图不代表通电完成后的结果 | 题注明确为连接方案或结构示意，验证章节直接写“整机通电测试尚未完成”，不删除真实的未完成状态 |
| 详见外部测试文件 | 将影响判断的条件、方法、数据与结果写入正文或附录，再按需要给出参考链接 |

“记录测试电流”“运行日志”“访谈逐字稿分析”“修订记录”等有实际含义的术语可以保留。访谈、历史研究等以原始叙述为研究对象的项目须保留方法、归属和引用。来源描述清理不取消引用规范，也不能把间接或未核实的信息改成确定结论。

自解释性还要求：

- 缩写、符号和状态值首次出现时说明含义；接口表写清方向、单位、触发条件及异常处理。
- 数字注明对象、条件和性质，区分配置值、额定值、估算值、单次测量和统计结果。单次测量不能改写成标称参数、公差或普遍性能。
- 成本交代统计范围和时间，区分采购总额、单套成本和批量估算；缺项不能默认为零。
- 参考装置、历史原型、当前实物和概念方案分别命名，不能因外观相似而混写成果；示意图参数与实际配置不一致时就地说明。
- 每个重要结论在本文有可理解的依据、条件和适用范围，新增分析与原始结果分清，未完成测试集中在相应验证或后续工作段落说明。

交付前脱离源文件通读一遍，同时检查正文、标题、表头、题注、图内文字和附录。审查脚本只能发现部分措辞或包内资源问题；它不验证图中文字、技术正确性、所有外部对象或整篇内容是否自洽。
