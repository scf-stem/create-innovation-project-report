# 实验数据处理与可视化

## 数据接收

优先保留原始文件，复制到工作目录后分析。记录：

- 文件名、时间范围和来源设备
- 字段、单位、采样周期和编码
- 软件版本、硬件版本和配置参数
- 测试工况、对照仪表和操作者
- 缺失值、重复值和异常说明

## 数据整理

任何整理都要能够重复执行：

1. 保留原始数据。
2. 明确删除、填补、平滑和截断规则。
3. 保存处理脚本或公式。
4. 同时保留样本量变化。
5. 区分传感器无效值、通信失败和真实极端值。

不能为了得到平滑曲线而隐藏真实异常。

## 指标计算

在报告中说明：

- 指标定义
- 分子、分母和单位
- 时间窗口
- 样本量
- 排除条件
- 对照值或比较对象

精度、成功率、实时性、稳定性、误差、调节时间和能耗都要回查原始记录。

## 图表选择

| 问题 | 推荐形式 | 必要字段 |
|---|---|---|
| 随时间变化 | 折线图 | 时间、数值、状态或目标线 |
| 不同方案比较 | 条形图 | 方案、指标、单位 |
| 两变量关系 | 散点图 | x、y、样本标识 |
| 组成比例 | 饼图仅限少量类别 | 类别、数量或占比 |
| 样本很少 | 表格 | 原始值、条件、结论 |
| 状态切换 | 阶梯图或事件时间线 | 时间、状态、原因 |

图题只说明画了什么，例如“温度与加热状态随时间变化”。结论和因果判断写在正文。

## 图表质量

- 轴、单位、图例和样本范围完整。
- 目标值、阈值和执行器状态可叠加，但不要让图过密。
- 颜色兼顾灰度打印和色觉差异。
- 同类图使用一致的单位、范围和配色。
- 不使用三维效果、装饰背景或夸张截断坐标轴。
- 图后写测试条件、观察结果和限制。

## 无数据时

没有原始记录时只能提供：

- 测试用例
- 数据字段模板
- 采样方案
- 判定标准
- 预期图表形式

不得绘制模拟曲线并当作项目结果。若演示模拟数据，图题和正文都要明确标为“模拟”。
