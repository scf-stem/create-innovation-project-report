# 图片与 DOCX 质量规范

## 选图原则

图片应证明项目做了什么，或帮助读者理解系统如何工作。每张图至少满足一个目的：

- 展示真实结构、实物或装配关系
- 展示代码、界面、运行状态或测试结果
- 解释架构、流程、数据流或控制逻辑
- 对比问题处理前后的关键差异

删除装饰性、重复性、与正文无关或无法辨认的图片。

## 图片来源顺序

1. 项目文件夹中的原始图片和截图
2. 从项目原视频、录屏中重新提取的清晰画面
3. 从 DOCX、PPTX、PDF 中提取的原始媒体
4. 对现有截图进行裁切、去除幻灯片边框和无关文字
5. 官方或可信页面的通用硬件照片
6. 新生成的结构、原理、架构和流程示意图

通用硬件图片只能说明器件外观或类别，不能证明项目实际使用了该型号。网络图片应保存来源信息供内部确认，但是否在成稿中列出处取决于提交要求。

## 视频取帧与内容裁切

适用于会议录像、屏幕演示、远程课堂和其他带播放器边框的素材，不依赖特定会议软件。

1. 回到可访问的原视频定位对应工程对象与状态，选择稳定、清晰且未被光标、弹窗或过渡动画遮挡的帧。不要把播放器窗口再次截图作为默认来源。
2. 检查相邻帧，确认操作和状态含义；一张静态图不能证明完整动作、持续运行或测试成功。只需截图时不生成新的演示视频。
3. 以共享内容或实物区域为边界，移除无关黑边、参会者区域、播放控件和窗口外框。必要的坐标、图例、端口、数值和告警必须保留。
4. 深色 CAD/EDA 画布、终端和仪器背景属于有效内容；黑色不能直接等同于无效边框。画面布局变化时逐帧调整裁切区域，禁止套用一个固定裁切框。
5. 保持比例与可读字号，检查有效 PPI。高分辨率原帧优先，禁止用生成式补画、涂抹报错或修改 DPI 元数据伪造清晰度或成功状态。
6. 原视频及原帧只读，在工作区保存时间点和裁切范围用于复核。正文题注以工程对象和状态命名，不默认写录制日期、软件名称或“设计截图”。需要时间条件或来源归属时按要求保留。

缺少可访问原视频时，可以处理现有图片，并如实说明仅完成裁切；不能声称已重新取帧。替换后在文档实际显示尺寸下检查每张图、题注和相邻正文，避免裁切掉信息或留下细黑条。所需图片须内嵌到 DOCX，不能依赖本机路径显示。

## 生成图与重制图

报告新生成或重制的流程、架构、状态、时序、接口连接、原理、结构、爆炸与操作示意图片统一执行 `$imagegen` 技能。不得以 SVG、Mermaid、Graphviz、Pillow、Canvas 等绘图结果或其转出的 PNG/JPEG 代替 imagegen 成图。既有真实照片、界面截图、视频取帧及已有 CAD 原始成果保持原貌；实测统计应由真实数据计算并采用可编辑表格或原生图表，不能让图像生成工具编造测量曲线或数据。

生成前读取 [工程与论文配图画法](engineering-diagram-conventions.md)，确定图类型、标准版本或参考论文，再把节点、符号、连线、条件和标注整理为文字规范交给 imagegen。普通框图、程序流程图、UML 活动图、状态图和时序图各有用途，不混用符号语义。图形美观不能代替逻辑与工程验收。

制作与替换时：

1. 盘点正文和附录全部图片，区分真实资料、工程原生导出、既有 imagegen 图片及本轮需重制示意图；不能只替换一张代表图。
2. 逐图记录图号、说明对象、来源、适用规范、关键标签、参数、箭头与分支关系；先核对项目逻辑，再写提示词。提示词采用中文宋体风格、英文及数字 Times New Roman 风格，保证在 Word 实际尺寸下清晰。
3. 使用可用的 imagegen 技能与工具，每张独立图片单独调用。编辑本地图片前先查看原图，保留技术内容并按本轮要求重绘；不以代码绘图或事后叠字替代生成结果。
4. 按所选规范逐张检查节点形状、连线类型、中文文字、英文标识、数值、单位、箭头方向、分支条件、状态迁移、接口及装配关系。有错误时通过 imagegen 定向修改并再次验收，精确长说明优先放在可编辑正文或图外题注。
5. 将选用的 PNG/JPEG 保存到项目目录并内嵌文档。保留提示词、工具模式、原始生成输出路径、成图路径与哈希，以及对应图号和检查结果供内部追溯。
6. 保持图题、编号、正文引用和图片比例；替换后完整渲染并检查所有受影响页面与后续分页。没有 imagegen 能力时继续已有真实资料可完成的部分，如实说明生成图步骤受阻，不默默改用 SVG 或代码绘图。

保持全篇风格一致：

- 使用统一的线条粗细、配色、字体感和视角
- 图内只保留短标签、箭头、端口名和必要状态
- 不在图片内部放置与图题重复的标题
- 不把段落、操作步骤或 PPT 说明文字塞进图中
- 不伪造实物、测试结果、软件界面或测量数据

生成图适合架构、流程、原理和概念关系，不适合作为“已完成测试”的证据。

机械爆炸图按 [exploded-view-and-appendix.md](exploded-view-and-appendix.md) 执行。已有 CAD 原生爆炸视图可作为真实资料与参考；新增或重绘爆炸图统一由 imagegen 生成，并提供真实项目参考图和零件清单。

## 标注与题注

- 图内标注控制在词组级，如“相机输入”“识别节点”“停车指令”。
- 图题控制在一行内，如“图 7-2 控制系统硬件连接关系”。
- 正文在图前或图后解释观察重点，不重复朗读题注。
- 题注直接写对象及必要运行状态，图内短标签与正文同步。将参数含义、方案与实物的区别写在对应正文中，缺少验证的事项留在内部清单；默认正式报告不增加待测说明。按 [成稿内容规则](content-policy.md) 核对图内文字与正文，避免模板或旧图保留相反的内容。
- 同一章节使用“图 章节号-序号”编号。
- 正文使用“见图 7-2”或“见附图 A-1”引用，引用编号必须存在对应题注。
- 用户要求“不要标题”时，先确认指图内标题还是图题；批注目标明确时只改该图。

## 实物照片附录

照片较多时，从以下视角选择代表图：

- 整体外观
- 开门或拆盖后的内部布局
- 关键执行器、传感器或控制板
- 界面和操作区域
- 后部、底部或维护结构

附录每张照片写“附图 A-1”式编号和可见部件说明。正文相关章节至少引用一次。相似角度、信息重复或无法辨认的照片不纳入。

正文和编号稳定后使用 `scripts/appendix_images.py` 终装，禁止在润色或目录更新过程中反复删除、复制附录图片。

## 版面检查

- 图片保持原始比例，不拉伸。
- 单图宽度不超过版心；细节截图可使用全宽。
- 多图组合要有一致高度、间距和子图标识。
- 图与题注保持同页，题注后留出适当段间距。
- 低分辨率图片不要放大到文字无法辨认。
- 以“源像素 ÷ 文档中实际英寸尺寸”计算有效 PPI。用户要求 300 dpi 时，按有效 PPI 检查，不只修改图片 DPI 元数据。
- 裁切时保留任务栏、坐标、图例或状态栏中真正有证据价值的部分。

## 渲染检查清单

- 封面信息完整，层级、留白和对齐符合用户模板或已确认设计
- 目录页码与标题层级正常
- 标题不落在页尾
- 图题、表题与对象没有跨页
- 表格没有超出版心或截断
- 图片没有压扁、模糊、遮挡正文
- 中文正文、标题与西文字体分别符合本轮规范；检查主题字体、直接格式和继承关系，避免缺字或字形替换。具体设置和有效字体检查见 [论文式中西文字体与检查](academic-fonts.md)
- 自动更新目录后，目录条目的中文与英文、数字字体仍正确；原生数据图表字体与正文要求一致，imagegen 示意图的短标签清晰且字形协调，原始界面截图和照片保持原貌
- 全部本轮生成或重制示意图均有 imagegen 生成记录；DOCX 中没有 SVG 资源，也没有用普通程序绘图代替 imagegen 的示意图
- 页眉、页脚和页码连续
- 章节编号、图号、表号连续
- 最后一页没有异常空白或残留说明

具备渲染能力时，每次交付前完整渲染并逐页检查；局部修改重点复查修改页、相邻页、目录及最后一页，仍需确认全篇没有分页连锁变化。封面、字体、图片尺寸或表格高度变化后尤其要检查后续页码。缺少渲染能力时按任务配置说明未完成项，不将 XML 检查冒称为版面检查通过。
